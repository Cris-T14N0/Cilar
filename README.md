# Cilar - Artigos para o Lar

A simple, responsive HTML/CSS website for Cilar, a local store in Foros de Salvaterra, Portugal, offering home goods, cleaning products, clothing, technology items, and CTT postal services.

## About the Store

Cilar is a community-centered store that has been serving the Foros de Salvaterra community for over 20 years. The store offers a wide variety of everyday essentials and serves as an official CTT Point (Portuguese postal service partner).

## Website Features

### Sections
- **Home/Hero** - Main landing section with store branding
- **Gallery** - Interactive carousel showcasing store interior and products
- **CTT Services** - Detailed information about postal services offered
- **History** - Story of the store and its mission
- **About** - Information about store owner Cila Cunha
- **Location** - Interactive Google Maps integration
- **Contact** - Contact form and store information

### Product Categories
- Daily utilities and household items
- Cleaning products and home care
- Clothing and accessories
- Mobile phones and technology

### CTT Services Available
- National and international mail
- CTT Express packages
- Postal orders (money transfers)
- Printing and photocopying
- Mobile top-ups
- Bill payments and public services

## Technical Details

### Technology Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Framework**: Bootstrap 5
- **Icons**: Bootstrap Icons
- **Template**: Based on TemplateMonster Kind Heart Charity template
- **Hosting**: OVH Cloud

### Key Features
- Fully responsive design
- Mobile-friendly navigation
- Interactive image carousel with thumbnail previews
- Google Maps integration
- Contact form with Web3Forms integration
- Social media integration (Facebook, Instagram)
